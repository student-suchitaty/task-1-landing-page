# Task 1 – Responsive Landing Page (HTML & CSS)

A simple, responsive landing page for a fictional pottery studio, **Glazeworks**, built as part of the Web Development Internship (Elevate Labs).

## What I built
- **Header** with a logo and nav links. The nav collapses into a toggle menu on screens below 768px.
- **Hero section** with a heading, paragraph and call-to-action buttons.
- **Classes section** with three cards laid out using CSS Grid.
- **Footer** with social links and copyright text.

## Concepts used
- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS Flexbox (header, footer, buttons) and CSS Grid (hero, cards)
- Media queries for responsiveness
- CSS custom properties (variables) for colors and fonts
- Accessible focus styles and reduced-motion support

## Tools
- VS Code
- Live Server extension
- Chrome Browser

## Files
- `index.html` – page structure
- `style.css` – styling and media queries
- `README.md` – project description

## How to run
1. Clone or download this repository.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Resize the browser window to test responsiveness.

## What I learned
- How to structure a page with semantic HTML
- How Flexbox and Grid differ and when to use each
- How media queries make a layout adapt to different screen sizes
